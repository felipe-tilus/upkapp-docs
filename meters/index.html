    Meter & Data Tracking

    While many maintenance tasks are based on the calendar, some of the most critical upkeep routines depend entirely on actual usage. Tracking tasks by calendar dates when they should be measured by wear-and-tear leads to over-maintenance (wasting money) or under-maintenance (causing breakdowns).

    Upkapp solves this with Meters & Data Tracking, allowing you to trigger repetitive tasks based on independent counters like mileage, hours of operation, production cycles, or any custom metric.

    What is a Meteror counter?

    A Meter in Upkapp is an independent counter that you create and associate with one or more Jobs. Instead of counting days, Upkapp counts units of use.

    Common examples of Meters include: * Mileage (Odometer): For delivery vans, corporate cars, or trucks. * Operating Hours (Hour Meter): For air compressors, forklifts, generators, or industrial machinery. * Production Cycles/Clicks: For printing machines, injection molds, or automated equipment. * Elapsed Quantities: Any custom numeric data that increments over time.

    The 5-Second Quick Update Interface

    The biggest failure of traditional asset management systems is that updating counters is tedious, so teams stop doing it. Upkapp eliminates this friction with our proprietary Quick Update Interface.

    You do not need to navigate through complex asset sheets just to log a number. Upkapp provides a streamlined dashboard where updating any meter takes exactly 2 clicks and 5 seconds:

    1. Click the Update Counters floating action or tab.
    2. Type the new current value next to the asset (e.g., entering 45200 for a van's mileage) and hit enter.

    The system instantly saves the data, updates the history, and evaluates all linked jobs in the background.

    Developer-Friendly: Automated Updates via API

    If your business uses IoT sensors, GPS/telematics tracking software, smart machinery, or custom internal systems, you do not need to type numbers manually at all. Upkapp offers a powerful API that allows you to automatically push meter readings from your existing software directly into Upkapp in real-time.

    How to Set Up Meter Tracking

    Automating a usage-based workflow involves two simple parts: creating the meter and linking it to a job.

    Step 1: Create the Meter

    1. Go to the Meters section in the main navigation menu.
    2. Click Create New Meter.
    3. Give it a clear name (e.g., Van A Mileage or Forklift #2 Hours).
    4. Set the Unit of Measurement (e.g., Miles, Hours, Cycles).
    5. Input the Current Value to set your baseline starting point and click Save.

    Step 2: Link the Meter to a Job

    1. Navigate to Items and open the asset you want to control (e.g., Delivery Van A).
    2. Click Create Job (or edit an existing one).
    3. Under Trigger Type, change it from Time-Based to Meter/Counter.
    4. Select the specific Meter you created in Step 1 from the dropdown menu.
    5. Set the Frequency Interval (e.g., trigger this job every 5,000 miles).
    6. Click Save.

    Real-World Example: Fleet Maintenance

    Imagine you manage a transport van. You configure the system like this:

    • Meter: Van Mileage (Current baseline: 10,000 miles).
    • Job Linked: Change Engine Oil (Set to trigger every 5,000 miles).

    How Upkapp Automates This: * The system knows the next oil change is due when the meter hits 15,000 miles. * Every Friday, your driver uses the 5-second interface to type in the current odometer reading. * Once the driver enters a value of 15,002, Upkapp automatically fires a Work Order titled Change Engine Oil directly to your maintenance team's dashboard. * When the task is completed, the system dynamically resets the target, preparing to trigger the next work order automatically at 20,002 miles.
